# G0: Repository, CI program, generator skeleton

Read first: `AGENTS.md`, ADR-0001, ADR-0004, `shared/spec/PORT-PLAN.md` phase 0.

Precondition: `shared/VERSION` holds a hub commit SHA, not `pending` (hub H0). G0-05 also needs
hub H3. If either is unmet, stop and tell the human.

## Tasks

### G0-01 Module
`go.mod`: `module github.com/sanamhub/nepdate-go`, `go 1.24`, no `require`. `doc.go`:
package comment (what it is, range, zero value, link to `shared/spec/`) and
`//go:generate go run ./internal/gen`. `CHANGELOG.md` with an empty `## [Unreleased]`.
AC: `go build ./...` and `go vet ./...` pass; `go list -m all` prints only
`github.com/sanamhub/nepdate-go`.

### G0-02 Generator skeleton (`internal/gen/main.go`)
Reads `shared/data/calendar/bs-calendar.json` with `encoding/json` (fine here: dev time only), checks
299 years × 12 lengths in 29..=32, writes `calendar_gen.go` with the header
`// Code generated by internal/gen. DO NOT EDIT.` and, for now, only `const minYear = 1901`,
`const maxYear = 2199`. Output is `gofmt`-ed (`go/format.Source`) and deterministic.
Flag `-check`: generate in memory, compare with the file on disk, print the name of each file
that differs and exit 1; write nothing (ADR-0001 §5).
AC: running it twice gives identical bytes; `-check` exits 0 on a fresh tree and 1 after one byte
of `calendar_gen.go` is changed; a unit test in `internal/gen` that feeds a month length of 33
gets an error naming the year and month.

### G0-03 CI program (`internal/ci/main.go`)
Runs the gates in ADR-0004 in order, printing each command, stopping at the first failure, and
ending with one summary line `ci: <passed>/<total> gates passed` (`ci: 5/5 gates passed` until G4
adds gate 6). `golangci-lint` and `govulncheck` are skipped with a warning when not on `PATH`; a
skipped gate counts as passed. Gate 3 covers only packages that exist (`.` until G4 adds
`./patro`), and a package that prints `coverage: [no statements]` passes. Subcommand
`release-check vX.Y.Z`: exits 0 only if `CHANGELOG.md` has a line starting
`## [X.Y.Z] - ` followed by a `YYYY-MM-DD` date, and the argument matches `v<semver>`.
AC: exits non-zero when a file is not `gofmt`-ed; `release-check v9.9.9` exits non-zero;
`release-check 0.1.0` (no `v`) exits non-zero.

### G0-04 Lint config
`.golangci.yml` exactly as ADR-0004 lists. AC: `golangci-lint run` passes on the skeleton.

### G0-05 GitHub Actions and repository files
- `ci.yml`: matrix os × Go (ADR-0004), plus `GOARCH=386` on Linux; runs `go run ./internal/ci`;
  `golangci/golangci-lint-action`; `golang/govulncheck-action`; job `shared-check` using the hub's
  reusable workflow. Every action pinned by SHA; `permissions: contents: read`; `concurrency`.
- `shared-sync.yml`: the hub's reusable workflow, `regenerate: go generate ./...`, cron
  `15 3 * * 2` (Tuesday 03:15 UTC) plus `workflow_dispatch`.
- `.github/dependabot.yml` (`github-actions` weekly; `gomod` for `benchmarks/` only),
  `pull_request_template.md`, `ISSUE_TEMPLATE/` (bug report: input, expected, actual, version, Go
  version, OS), `SECURITY.md`, `CONTRIBUTING.md` (points to AGENTS.md rules and the writing style).
- Human task: create `sanamhub/nepdate-go`, branch protection on `main`, environment `production`.

AC: CI green on the first PR; every `uses:` line is a 40-character SHA with the version in a comment.

## Checkpoint (agent stops here for review)
